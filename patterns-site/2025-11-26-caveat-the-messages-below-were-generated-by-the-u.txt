     Overview

     Build a Hugo-based static documentation site in /patterns-site

     individual, richly-detailed documentation pages with runnable code

     - Hugo - Static site generator (Go-based, fast)
     - Theme: hugo-book or hugo-geekdoc (documentation-focused themes with

     - Copy-to-clipboard: JavaScript snippet for code blocks

     Implementation Steps

     Step 1: Initialize Hugo Project

     - Create /patterns-site directory
     - Run hugo new site . to scaffold
     - Add hugo-book theme as git submodule
     - Configure hugo.toml with site settings, menu, and code highlighting

     Step 2: Create Base Templates & Styles

     - Configure Chroma syntax highlighting for Go
     - Add copy-to-clipboard JavaScript for code blocks
     - Set up navigation sidebar with pattern categories

     Step 3: Create Pattern Content Files

     For each of the 16 patterns, create an individual markdown file with:
     - Front matter (title, weight, description, tags)
     - Expanded explanation of the concept
     - Real-world use cases with examples
     - Linux internals deep-dive
     - Complete, runnable Go code examples
     - Common pitfalls and best practices
     - Related patterns cross-references

     Step 4: Content Enhancement

     Expand each pattern beyond the current PATTERNS.md content:
     - Add "Try it yourself" sections with instructions
     - Include error handling in code examples
     - Add diagrams where helpful (ASCII or embedded SVG)
     - Link to external resources (man pages, Go docs)

     Step 5: Homepage & Navigation

     - Create landing page with pattern overview
     - Add search functionality (Hugo's built-in or Lunr.js)
     - Organize patterns by category (Process, IPC, Filesystem, Security)

     Step 6: Build & Serve Scripts

     - Add Makefile or npm scripts for common tasks
     - Add .gitignore for Hugo build artifacts
     - Document local development workflow

     Pattern Categories (for sidebar organization)

     1. Process Management: Shell Wrapper, Graceful Shutdown, Daemonization
     2. File System: File Locking, File Watching, Embedded Assets
     3. IPC & Networking: Unix Domain Sockets, PTY Control, Stdin Detection
     4. Security & Isolation: Namespaces, LD_PRELOAD, Memfd Execution
     5. Binary Manipulation: Self-Updating, ELF Modification, Shim 
     Executables, eBPF

     Key Files to Create

     1. patterns-site/hugo.toml - Main config
     2. patterns-site/content/_index.md - Homepage
     3. patterns-site/content/patterns/_index.md - Patterns landing
     4. patterns-site/content/patterns/*.md - 16 pattern files
     5. patterns-site/static/js/clipboard.js - Copy functionality
     6. patterns-site/Makefile - Build commands

     Commands

     # Development
     cd patterns-site && hugo server -D

     # Build for production
     cd patterns-site && hugo --minify

     # Output will be in patterns-site/public/
